# 多智能体科研协作平台 (Scientific Research Collaboration)

本模块基于 **openclaw** 底座开发，旨在将系统从简单的问答工具转变为深度参与科研创新生命周期的“数字科研团队”。通过多人类专家与多专业智能体（Agent）在同一上下文中的协同，实现从灵感激发到报告生成的全链路自动化与人工干预。

---

## 核心特性

### 1. 多线交织协作 (Interwoven Collaboration)

- **共享上下文**：支持多个科研人员（Human）与多个子智能体（如检索 Agent、整理 Agent、报告 Agent）在同一任务流中共同推进。
- **任务动态拆解**：系统实时监听人类专家的讨论，根据指令自动拆解科研任务并分配路由。
- **透明化推理**：实时流式输出 Agent 的“思考过程（Mindset）”及调用的工具参数，消除 AI 执行的“黑盒”效应。

### 2. 精准挂起与人工干预 (Human-in-the-Loop)

- **关键节点拦截**：当 Agent 准备执行高危动作（如修改核心数据）或进入下一关键子流程前，系统自动进入 **Pending（挂起）** 状态。
- **审批控制台**：
  - **发起者特权**：仅任务发起者拥有审批权，可收到强提醒拦截卡片。
  - **Diff 比对**：支持对不同 Agent 产出的方案或报告进行可视化差异比对。
  - **在线修正**：发起者可手动修改参数或需求，点击 **Approve（批准）** 后底层流转才会继续。

### 3. 任务管理与异步审批

- **角色权限隔离**：明确区分“我发起的任务”（拥有审批权）与“我参与的任务”（拥有建议权）。
- **跨任务通知**：当用户在处理 A 任务时，若 B 任务触发审批挂起，用户可通过侧边抽屉快速完成审批，无需切换界面。

---

## 科研工作流示例

1.  **Idea 激发**：智能体根据研究方向（如：可视化大模型推理过程）自主头脑风暴，提供初步假设。
2.  **全自动执行**：
    - **检索 Agent**：自动联网搜索前沿文献和开源方案。
    - **整理 Agent**：负责数据清洗、归纳与逻辑梳理。
3.  **人工审查**：在合成报告前触发 Pending，研究人员通过 Diff 界面调整演进建议。
4.  **成果产出**：报告 Agent 合成结构化的研究报告或技术白皮书。

---

## 技术实现 (后端 Hook 系统)

- **流程阻断**：通过注入 Hook 机制，阻断 openclaw 原有的自动流转，实现 HITL（人工干预）逻辑。
- **指定确认**：支持在执行过程中等待特定人员（如导师或项目负责人）的回复或确认。
- **选择性进化**：根据用户的修改记录或反馈（点赞/点踩），触发轻量级反思，并将经验法则追加至智能体的 `Mindset.md` 中实现持续进化。
