# PRD: AIEMAS 多智能体协作聊天界面增强

## 1. 简介

在 AIEMAS 多智能体协作平台中，复杂的任务通常由一个根智能体接收，并根据预定义的拓扑关系或动态分发逻辑，将子任务委派给多个专业智能体。目前，聊天界面主要聚焦于线性对话及单一 SOP 展示，使用户在面对多 Agent 级联协作时存在“过程黑盒”的痛点。

本 PRD 旨在重构 `chat-view` 界面，引入**三层级视图切换（会话/协作/观测）**，提升用户对复杂协作场景的透明度与掌控感。

## 2. 核心目标

1.  **多级视图架构**：提供“会话”、“协作”、“观测”三种视图，满足用户从宏观结果获取、深度交互到微观过程监控的不同需求。
2.  **全局拓扑感知**：实时渲染当前会话涉及的所有智能体及其级联关系（DAG 图）。
3.  **多轨道 SOP 观测**：支持并行监控多个参与协作的智能体的 SOP 执行状态、详细步骤及实时日志。
4.  **人机协同透明化**：支持在协作过程中对特定子智能体进行人工干预（Human-in-the-loop）。

## 3. 需求说明（UI/UX 核心设计）

### 3.1 视图切换控制器 (View Switcher)

- **位置**：在聊天界面顶部（Header）提供常驻的视图切换组件（Segmented Control）。
- **模式**：支持 **会话 (Session) | 协作 (Collaboration) | 观测 (Observation)** 无缝切换。

### 3.2 会话视图 (Session View)

- **定位**：聚焦最终结果与线性对话。
- **UI 布局**：继承现有的单栏瀑布流聊天界面。
- **功能**：
  - 展示根智能体的回复、合并后的关键里程碑消息（Milestones）。
  - 默认隐藏复杂的子智能体流转细节，保持界面整洁。
  - 顶部保留**多轨道 SOP 进度摘要**，支持通过切换或悬停查看各级联 Agent 的阶段性状态。

### 3.3 协作视图 (Collaboration View)

- **定位**：人机协同与多智能体交互。
- **UI 布局**：分屏或画中画布局。
  - **左侧/顶部**：动态拓扑图 (Topology DAG) 缩略区，展示 Agent 级联关系和消息流向指示（如高亮边、粒子流动效果）。
  - **右侧/主体**：**多窗口消息流 (Multi-Window Chat)**。不同 Agent 的消息在独立的子窗口或卡片流中并行展示。每个窗口顶部集成该 Agent 的 **Mini SOP 进度条**，实时显示其当前步骤与进度百分比。
- **功能**：用户可以直接针对特定子 Agent 的气泡进行追问或人工干预，消息路由逻辑透明。

### 3.4 观测视图 (Observation View)

- **定位**：全景监控、过程白盒化与故障排查。
- **UI 布局**：以拓扑与图表为主的仪表盘界面，弱化常规对话。
  - **主体区域**：可视化多智能体间消息路由关系 (Topology DAG) 的全尺寸图谱。
  - **节点详情**：点击特定 Agent 节点时，侧边栏或底部抽屉滑出该 Agent 的专属面板。
- **功能 (专属面板)**：
  - **SOP 进度条**：基于 `skill.progress` JSONL 的增量更新，展示当前 Agent 的 SOP 详情。
  - **隔离日志**：提供终端风格的日志视图（Logs），不同 Agent 的日志完全隔离，互不穿插。

## 4. UI/UX 设计规范 (Rich Aesthetics)

为了确保多层级视图的专业性与现代感，UI 设计需遵循以下规范：

- **极简画板 (Topology Style)**：拓扑图采用极简线条与半透明卡片风格（Glassmorphism），背景使用微弱的点阵网格，确保在复杂协作时不干扰用户视觉重心。
- **微动效与反馈 (Micro-animations)**：
  - **活跃节点**：采用“呼吸灯”效果或外发光动画表示正在工作的 Agent。
  - **消息流动**：Agent 间通信时，连接线上展示粒子流动效果，直观呈现数据流向。
  - **视图切换**：三视图切换时使用平滑的渐变或位移动画。
- **现代配色与排版**：
  - 使用 Google Fonts (如 Inter 或 Outfit) 提升可读性。
  - 采用经过调优的深色模式（Dark Mode）与护照配色方案，保持高溢价感。
- **流畅交互**：拓扑画板支持丝滑的缩放与平移（Zoom & Pan），并支持点击节点时的弹性展开动画。

## 5. 验收标准

1.  **视图切换流畅度**：三视图切换时不丢失当前滚动位置、已输入的草稿内容和已加载的上下文状态。
2.  **拓扑与消息联动**：在协作视图中，拓扑图节点的闪烁或状态变化需与多窗口中新消息的到达、SOP 状态机变更严格同步。
3.  **数据隔离性**：观测视图中，点击不同 Agent 节点必须能准确渲染对应的独立 SOP 步骤和日志缓冲区。
4.  **持久化恢复**：重新进入会话时，能够根据 Session 级联历史（sessionKey 派生规则）重建多视图状态及拓扑图。
5.  **设计还原度**：UI 需高度还原 Glassmorphism 效果与微动效指标，确保视觉体验优于竞品。
