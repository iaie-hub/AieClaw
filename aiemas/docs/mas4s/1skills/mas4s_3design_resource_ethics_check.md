## 阶段 3 - 步骤 5：资源与伦理预检 (Resource & Ethics Check) 设计方案

### 一、 设计理念

1.  **算力可行性前置 (Compute Feasibility)**：在正式编写代码前，对实验所需的 GPU 小时数、显存占用进行科学估算，防止中途因资源耗尽而停滞。
2.  **合规红线扫描 (Compliance Check)**：检查所引用的数据集、预训练模型、API 的 License 许可，确保科研成果符合开源或商用合规要求。
3.  **伦理风险评估 (Ethics Review)**：评估模型可能存在的偏见（Bias）、安全性风险（Safety）及隐私泄露风险，并预设缓解措施。

### 二、 设计方案

#### 资源与伦理审计矩阵

| 维度核心模块                     | 核心内容                                            | 目标下游受众      |
| :------------------------------- | :-------------------------------------------------- | :---------------- |
| **资源估算 (Resource Estimate)** | GPU 型号需求、VRAM 需求、估计训练/推理时长。        | 实验室管理员 / PI |
| **许可与合规 (License Audit)**   | 数据集 License、模型 License、外部 API 费用与额度。 | PI / 法务         |
| **伦理与偏见 (Ethics & Bias)**   | 偏见扫描计划、潜在负面影响、数据隐私风险评估。      | PI / 伦理委员会   |

### 三、 实现流程

| 步骤 | 动作           | 说明                                                            |
| :--- | :------------- | :-------------------------------------------------------------- |
| 1    | 情报加载       | 读取 `method_blueprint_en.json` 与 `eval_protocol_en.json`。    |
| 2    | 资源推算引擎   | 基于模型参数量（如 7B, 13B）与样本量推算峰值显存与 GPU 小时数。 |
| 3    | 许可合规匹配   | 检索图谱中相关组件的协议类型（MIT, Apache 2.0, CC 等）。        |
| 4    | 伦理敏感词扫描 | 检测实验目标中是否包含隐私数据处理或可能诱导偏见的敏感词。      |
| 5    | 生成审计报告   | 生成 `resource_ethics_report.json` 与 Markdown 简报。           |

### 四、 输入参数

| 参数名            | 类型   | 必填 | 说明                              |
| :---------------- | :----- | :--- | :-------------------------------- |
| **run_id**        | String | 是   | 执行 ID。                         |
| **gpu_unit_cost** | Float  | 否   | 每小时 GPU 成本（用于财务预算）。 |

**必需输入文件**：

- `method_blueprint_en.json`
- `eval_protocol_en.json`

### 五、 输出参数

**固定输出文件**：

- `resource_ethics_report.json`：中英混合资源与伦理报告原始数据。
- `resource_ethics_report_en.json`：纯英文版（机器存档）。
- `resource_ethics_report_cn.json`：纯中文版（前端渲染）。
- `resource_ethics_report_brief.md`：审计简报。

### 六、 核心字段定义

| 类别     | 字段名称                | 描述                             |
| :------- | :---------------------- | :------------------------------- |
| **资源** | `gpu_hour_estimate`     | 预估的总 GPU 小时数。            |
|          | `peak_vram_requirement` | 预估的单节点峰值显存（GB）。     |
| **合规** | `license_compatibility` | 判定当前工具链是否满足合规要求。 |
| **伦理** | `bias_mitigation_plan`  | 针对潜在偏见的应对预案。         |

### 七、 示例

#### 7.1 运行示例

```bash
python3 scripts/mas4s_design_resource_ethics_check.py '{"run_id": "run_20260430"}'
```

#### 7.2 审计简报示例

> ## 5. 资源与伦理预检报告
>
> ### 5.1 资源预估
>
> - **GPU 时长**: 约 240 小时 (基于 8xA100 节点)。
> - **预算预警**: 显存需求 > 40GB，建议使用 A100/H100 实例。
>
> ### 5.2 伦理说明
>
> - **偏见风险**: 多语言数据源可能存在地域文化偏差。
> - **对策**: 在评估环节引入平衡采样机制。

### 八、 SOP 观测支持

- **进度上报**：上报 `正在评估计算资源足迹...` 与 `正在执行模型伦理合规扫描...`。
- **预警机制**：若预估资源超过当前 Agent 配额，将触发 `RESOURCE_EXCEEDED` 警报并通知 PI。
